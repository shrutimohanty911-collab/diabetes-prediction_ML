# 🩺 Diabetes Risk Predictor — Enhanced ML + Explainable AI

Predicts diabetes risk from patient medical data, using multiple ML models,
hyperparameter tuning, an ensemble classifier, and SHAP-based explainability —
deployed as a live Streamlit web app.

## 🚀 What makes this different from the basic version

Most PIMA-dataset diabetes projects skip a key issue: several columns
(Glucose, BloodPressure, SkinThickness, Insulin, BMI) use `0` to mean
**missing data**, not an actual zero value. Left as-is, this quietly hurts
model accuracy. This project detects and properly imputes those values
before training.

On top of that:
- **4 models compared**: Logistic Regression, Random Forest, XGBoost, SVM
- **Hyperparameter tuning** via GridSearchCV + Stratified 5-fold CV for every model
- **Soft-voting ensemble** combining the top 3 models
- **SHAP explainability** — every prediction shows *which factors* drove it, not just a yes/no
- **Deployed web app** with real input validation (not just a notebook)

## 📊 Dataset

- PIMA Indians Diabetes Dataset (768 records, 8 features)
- Source: loaded directly from a public mirror in `train_model.py` (no manual download needed)

## 🛠 Tech Stack

Python, pandas, NumPy, scikit-learn, XGBoost, SHAP, Streamlit, Matplotlib

## ▶️ How to Run

1. Clone the repo and install dependencies:
```bash
pip install -r requirements.txt
```

2. Train the model (downloads the dataset automatically, trains all models, saves the best one):
```bash
python train_model.py
```

3. Launch the app:
```bash
streamlit run app.py
```

## 🌐 Deploy for Free (Streamlit Community Cloud)

1. Push this repo to GitHub (include the `.pkl` files generated by `train_model.py`).
2. Go to [share.streamlit.io](https://share.streamlit.io), sign in with GitHub.
3. Click "New app" → select this repo → set main file to `app.py` → Deploy.
4. You'll get a free public link like `yourapp.streamlit.app`.

## 📈 Results

Model comparison (ROC-AUC on held-out test set) is printed by `train_model.py`
and saved to `model_report.txt` after training — exact numbers depend on the
tuned hyperparameters found in your run.
